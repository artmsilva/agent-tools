# Domain docs

Before exploring, read root `CONTEXT-MAP.md`, then the relevant package `CONTEXT.md` and package/system ADRs. Missing context docs are not blockers; proceed silently.

This is a multi-context repository:

- root `CONTEXT-MAP.md` routes packages with domain docs
- package contexts live at `packages/<package>/CONTEXT.md`
- package ADRs live at `packages/<package>/docs/adr/`
- system-wide ADRs may live at root `docs/adr/`

Use glossary vocabulary in issue titles, proposals, and tests. Surface conflicts with existing ADRs explicitly.
