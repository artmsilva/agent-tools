# Issue tracker: GitHub

Issues and PRDs live in GitHub Issues for `artmsilva/agent-tools`. Use the `gh` CLI for create/read/comment/edit/close operations.

## Conventions

- Infer the repository from `origin` when inside this clone.
- A bare `#42` may be an issue or PR; resolve with `gh pr view 42`, then `gh issue view 42`.
- When a skill says “publish to the issue tracker,” create a GitHub issue.
- When a skill says “fetch the relevant ticket,” fetch its body, labels, and comments.

## Pull requests as a triage surface

PRs as a request surface: no.
