# Package instructions

## Scope

Host-side control plane and CLI for durable, credentialless local Guest environments (Drydock) built on Apple `container`.

## Validation

```sh
npm test
npm run check
npm run pack:check
```

Run Apple Guest smoke scripts only on Apple silicon with macOS 26 and the Apple `container` CLI.

## Guardrails

- Runs only on Apple silicon macOS with Apple `container` CLI installed; most scripts assume `process.platform === "darwin"` behavior (e.g. tar `--no-xattrs` flags in `workspace-handoff.ts`).
- Environment/tombstone names must match `NAME_PATTERN`/`ID_PATTERN`/`TOMBSTONE_PATTERN` regexes in `control-plane.ts`; do not relax these without checking every caller.
- Connector credentials and GitHub review-request approvals are host-only and single-use by design (`github-connector.ts`) — never route them through the Guest.
- `dist/` is generated by `npm run build` (which also copies `guest/` and `image/` into it); do not hand-edit build output.
- Tests run via Node's built-in test runner (`node --test src/*.test.ts`), not a separate framework — keep new tests in that convention.
